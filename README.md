# MOSS BBox Enhancer

用于 ComfyUI 的 MOSS 布局 JSON 导入、边界框编辑和尺寸映射插件。

## 功能

- 从 MOSS JSON 生成官方边界框元素数组。
- 在节点面板中可视化编辑边界框。
- 支持新增、删除、移动、缩放、多选和锁定边界框。
- 支持文字框、描述和调色板编辑。
- 支持背景图导入、粘贴、透明度调整和画布模式设置。
- 支持从生成图片的 PNG 元数据中提取提示词和布局信息。
- 支持固定坐标、等比缩放和暴力拉伸三种尺寸映射方式。
- 支持根据 JSON 中的边界框自动推测原始画布尺寸。

## 节点

### MOSS JSON 导入边界框

输入 MOSS 布局 JSON，输出：

- `元素数组`：官方画布使用的归一化元素数组。
- `边界框数组`：像素坐标边界框数组。
- `主提示词`：`summary.caption` 中的主提示词。
- `完整提示词`：包含边界框时输出完整 JSON，否则输出纯文本提示词。

可选连接 `image` 输入后，插件可以使用图片尺寸作为画布尺寸，并将图片显示为编辑面板背景。

节点还提供“导入图片中的提示词 JSON”按钮，可从带有 ComfyUI 生成参数的图片中提取 MOSS JSON、官方边界框或文本提示词。

`主提示词` 和 `完整提示词` 都是字符串输出，可以直接连接到正向提示词输入或正向文本编码节点：

- 使用 `主提示词`：只传递整体画面描述。
- 使用 `完整提示词`：包含边界框时传递完整 MOSS 布局提示词，没有边界框时等同于主提示词。

### MOSS BBox 尺寸映射器

将 MOSS JSON 中心坐标系的边界框映射到目标画布尺寸。

输出：

- `边界框数组`：可直接连接到官方 `Create Bounding Boxes` 节点的 `bboxes` 输入，或连接到 `MOSSImageLayoutPrompt` 的 `element` 输入。
- `映射后JSON`：保留映射后的 MOSS JSON 字符串。
- `目标宽度`
- `目标高度`

映射模式：

- `保持固定坐标(不缩放)`：保留边界框的中心坐标和尺寸。
- `保持长宽比(等比缩放)`：按较小缩放比例适配目标画布，并保持比例。
- `暴力拉伸(铺满画布)`：分别按宽高缩放，填满目标画布。

## JSON 格式

MOSS JSON 使用以画布中心为原点的像素坐标，BBox 顺序为：

```json
[ymin, xmin, ymax, xmax]
```

示例：

```json
{
  "summary": {
    "caption": "一个人在城市街道上行走"
  },
  "items": [
    {
      "label": "object",
      "caption": "人物",
      "bbox": [-256, -128, 256, 128]
    },
    {
      "label": "text",
      "caption": "招牌文字",
      "text": "OPEN",
      "bbox": [-100, 180, 20, 420]
    }
  ],
  "bbox_coord_space": "abs_centralized",
  "bbox_format": "yxyx"
}
```

官方元素数组使用 `0～1000` 的归一化坐标，字段名保持官方格式，例如 `type`、`bbox`、`desc`、`text` 和 `color_palette`。

## 使用建议

1. 将 MOSS JSON 连接到 `MOSS JSON 导入边界框` 或 `MOSS BBox 尺寸映射器`。
2. 如果目标画布尺寸与原 JSON 不同，使用尺寸映射器。
3. 将尺寸映射器的 `边界框数组` 连接到官方 `创建边界框(Create Bounding Boxes)` 节点。
4. 将官方画布输出的元素数组连接到 `MOSSImageLayoutPrompt`。
5. 将 `主提示词` 或 `完整提示词` 连接到正向提示词；需要布局控制时优先使用 `完整提示词`。


## 安装

将插件目录放入：

```text
ComfyUI/custom_nodes/MOSS_BBox_Enhancer
```

重启 ComfyUI 后即可使用。

## 说明

前端可以直接读取上游节点中的静态 JSON 文本控件。对于 Python 节点运行后才生成的动态输出，必须先执行工作流，上游结果生成后尺寸映射器才能读取并推测尺寸。

本插件不新增第三方依赖。
