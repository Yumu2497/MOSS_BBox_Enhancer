# MOSS BBox Enhancer

> v1.1.23

用于 ComfyUI 的 MOSS 布局 JSON 导入、边界框编辑、尺寸映射和按框色绘制边界框的插件。

## 功能

- 从 MOSS JSON 生成官方边界框元素数组。
- 在节点面板中可视化编辑边界框。
- 支持新增、删除、移动、缩放、框选多选、Alt 拖拽复制、锁定边界框。
- 支持文字框、描述、标签和调色板编辑。
- 支持对象 / 角色 / 文字三种条目类型。
- 支持撤销 / 重做（画布右下角按钮）和方向键微移。
- 支持右侧边界框列表拖动排序。
- 属性面板可独立悬浮并拖动，面板位置与尺寸会记住。
- 支持背景图导入、粘贴、透明度与尺寸调整、画布模式设置。
- 支持从生成图片的 PNG 元数据中提取提示词和布局信息。
- 支持固定坐标、等比缩放和暴力拉伸三种尺寸映射方式。
- 支持根据 JSON 中的边界框自动推测原始画布尺寸。
- 支持给每个框单独设置颜色，并按颜色把框绘制到图片上。

## 节点

### MOSS 布局编辑器

输入 MOSS 布局 JSON，输出：

- `元素数组`：官方画布使用的归一化元素数组。
- `主提示词`：`summary.caption` 中的主提示词。
- `完整提示词`：包含边界框时输出完整 JSON，否则输出纯文本提示词。
- `边界框`：绘制用的边界框数组，每项为 `{x, y, width, height, metadata, color}`，可直接连到「MOSS 绘制边界框」。它的 `metadata` 只有 `type` / `text` / `desc`，**不包含 `palette`**。

`边界框` 里的颜色来自面板里的「框色」（属性面板中，与调色板无关）：设置后画布描边也会用该颜色。颜色是框的附加属性，**不写入 `layout_json`**，只在这个输出里携带。这个输出也能直接连到官方「创建边界框」的 `bboxes` 输入——官方会读 `x/y/width/height/metadata`，`color` 被忽略。

各输出里颜色的归属是固定的：`元素数组` 的 `color_palette` 只放 JSON 里的调色板（构图信息，原样搬运，不会追加框色）；框色只出现在 `边界框` 的 `color` 字段里。没设颜色的条目不输出 `color`。

可选连接 `image` 输入后，插件可以使用图片尺寸作为画布尺寸，并将图片显示为编辑面板背景。

节点上的 `preview` 开关（默认开）控制执行后是否在节点下方显示画布预览：按当前画布尺寸画一张图，每个框用各自的颜色描边、左上角标序号；接了 `image` 时直接画在图片上。预览最长边 768px，等比缩小，存到 ComfyUI 的 temp 目录，不写入工作流。关掉就完全不生成图片。

选中多个框后拖动其中任意一个，整组会一起移动并保持相对位置；锁住的框不跟着动，整组贴到画布边界时会一起停住。

### 选择与快捷键

| 操作 | 效果 |
|---|---|
| 拖空白处 | 新建一个框，朝左上 / 右上 / 左下 / 右下任意方向都能拖出；拖动中越过起点会自动换向 |
| `Shift` + 拖空白处 | 框选，与选框相交的框全部选中；`Ctrl` 叠加为追加框选 |
| `Ctrl` + 点击框 / 数字标签 | 增减单个框到选区 |
| `Alt` + 拖动框 | 复制选中的框，拖动的是副本，原件留在原处 |
| `Ctrl` + `A` | 全选所有框 |
| `Ctrl` + `D` | 原地复制选中的框（副本与原件重合，复制后处于选中状态，可直接拖走） |
| `Esc` | 取消选择；框选拖到一半时作废这次框选 |
| `Ctrl` + `C` / `Ctrl` + `V` | 复制框到系统剪贴板 / 粘贴框或背景图 |
| `Delete` / `Backspace` | 删除选中框 |
| 方向键 / `Shift` + 方向键 | 微移 1px / 一个吸附步长 |

复制出来的框会继承原框的颜色、标签、描述和调色板等信息。快捷键只在编辑面板打开、且焦点不在文本输入框里时生效。

按住 `Alt` / `Ctrl` / `Shift` 时，画布顶部会弹出该组快捷键的文字提示，松开即收起；每次快捷键操作（复制、粘贴、全选、原地复制、删除、框选、微移、撤销等）完成后，也会在同一位置短暂显示操作结果，例如「已复制 2 个框」。提示不拦截鼠标事件，不影响画布操作。

节点还提供“导入图片中的提示词 JSON”按钮，可从带有 ComfyUI 生成参数的图片中提取 MOSS JSON、官方边界框或文本提示词。

`主提示词` 和 `完整提示词` 都是字符串输出，可以直接连接到正向提示词输入或正向文本编码节点：

- 使用 `主提示词`：只传递整体画面描述。
- 使用 `完整提示词`：包含边界框时传递完整 MOSS 布局提示词，没有边界框时等同于主提示词。

### MOSS BBox 尺寸映射器

将 MOSS JSON 中心坐标系的边界框映射到目标画布尺寸。

输出：

- `元素数组`：0–1000 归一化的官方元素数组，接 `MOSSImageLayoutPrompt` 的 `element` 输入。
- `映射后JSON`：保留映射后的 MOSS JSON 字符串。
- `目标宽度`
- `目标高度`
- `边界框`：映射后的像素框（左上角原点），可直接接官方 `Create Bounding Boxes` 的 `bboxes` 输入，或接「MOSS 绘制边界框」；条目本身带 `color` 时一并透传。

映射器没有框色通道（框色存在导入节点的面板里），也不会拿调色板首色冒充框色——JSON 里没写 `color` 就不带这个字段，绘制时用兜底色。

映射模式：

- `保持固定坐标(不缩放)`：保留边界框的中心坐标和尺寸。
- `保持长宽比(等比缩放)`：按较小缩放比例适配目标画布，并保持比例。
- `暴力拉伸(铺满画布)`：分别按宽高缩放，填满目标画布。

### MOSS 绘制边界框

把边界框按各自的颜色画到图片上。官方「绘制边界框」按 COCO 标签取固定颜色，这个节点改成读框自带的颜色。

输入：

- `bboxes`：边界框列表，可直接接上面节点的 `边界框` 输出；也支持官方 `[[{x, y, width, height}]]`、单个框对象或 JSON 字符串。
- `image`：底图，可选。不接时按框的最大范围生成一张深灰底图。
- `line_width`：线宽，默认 3。
- `show_index`：在框左上角画序号。
- `show_label`：在框内画描述 / 文字内容（放不下时自动跳过；多行文本压成一行显示，超宽按宽度截断）。
- `fallback_color`：没有携带颜色的框使用这个颜色，默认 `#ff4a4a`，节点上是取色器，点一下就能选。

颜色只取边框自带的 `color`，没有就用 `fallback_color`；`metadata.palette` 属于构图信息，不参与描边。

节点上的显示名是中文（边界框 / 线宽 / 显示序号 / 显示描述 / 兜底颜色），只改前端显示，输入 key 不变，老工作流照常读取。

输出：`图像`。

## JSON 格式

MOSS JSON 使用以画布中心为原点的像素坐标，BBox 顺序为：

```json
[ymin, xmin, ymax, xmax]
```

示例：

```json
{
  "summary": {
    "caption": "一个人在城市街道上行走"
  },
  "items": [
    {
      "label": "object",
      "caption": "人物",
      "bbox": [-256, -128, 256, 128]
    },
    {
      "label": "text",
      "caption": "招牌文字",
      "text": "OPEN",
      "bbox": [-100, 180, 20, 420]
    }
  ],
  "bbox_coord_space": "abs_centralized",
  "bbox_format": "yxyx"
}
```

官方元素数组使用 `0～1000` 的归一化坐标，字段名保持官方格式，例如 `type`、`bbox`、`desc`、`text`、`tags` 和 `color_palette`。编辑面板中的标签和调色板都可以通过 `+` 添加，双击或右键已有项目即可删除。

### 字段约束

- `label` 只有 `object`、`character`、`text` 三种，编辑面板顶部三个按钮切换。
- 只有 `label: "text"` 的条目带 `text` 字段；切回对象/角色时会自动删除该字段。
- `tags` 和 `palette` 为空数组时会从 JSON 中整个删除该字段，不输出 `"tags": []`。
- 官方元素数组的 `type` 只有 `obj` 和 `text`，所以 `character` 转换后等同 `obj`。角色身份由官方 `MOSSImageLayoutPrompt` 节点的 `character_boxes` 按**框序号**指定（例如 `1, 3`）。

### 坐标格式（两种官方写法都支持）

| 格式 | bbox_coord_space | bbox_format | 原点 | 画布尺寸 |
|---|---|---|---|---|
| **草稿**（官方 Pixel Layout draft） | `abs` | `xyxy` | 左上角 | 顶层 `width` / `height` |
| **模型**（ComfyUI 官方节点使用） | `abs_centralized` | `yxyx` | 画布中心 | 顶层 `width` / `height`（可选），或由节点控件给出 |

本插件统一以**模型格式**为规范。粘贴草稿格式的 JSON 时，绘制面板和两个节点会自动换算成 `abs_centralized` / `yxyx`，并把草稿里的 `width` / `height` 同步到画布的宽高控件，无需手动转换。

模型格式里也可以保留 `width` / `height`（用于记录画布尺寸）：它们会同步到画布控件，与控件双向保持一致；但**生成 `完整提示词` 时会自动剥离**，不会进入喂给模型的提示词。尺寸映射器的 `映射后JSON` 则会把它们更新为目标画布尺寸。

## 使用建议

1. 将 MOSS JSON文本 复制或连接到 `MOSS 布局编辑器` 或 `MOSS BBox 尺寸映射器`使用。
2. 如果目标画布尺寸与原 JSON 不同，使用尺寸映射器，保证尺寸不偏移，可以连接到`创建边界框`节点预览一下映射后的布局。
3. 将官方画布输出的元素数组连接到 `MOSSImageLayoutPrompt`。
4. 将 `主提示词` 或 `完整提示词` 可以直接连接或复制到正向提示词；需要布局控制时优先使用 `完整提示词`。


## 安装

将插件目录放入：

```text
ComfyUI/custom_nodes/MOSS_BBox_Enhancer
```

重启 ComfyUI 后即可使用。

## 说明

前端可以直接读取上游节点中的静态 JSON 文本控件。对于 Python 节点运行后才生成的动态输出，必须先执行工作流，上游结果生成后尺寸映射器才能读取并推测尺寸。

本插件不新增第三方依赖。
